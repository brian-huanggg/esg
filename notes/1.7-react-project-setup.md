# Step 1.7 建立 React 專案並看懂結構

## 目標與結果

- 目標：用 Vite 範本建立 `frontend/`，`npm run dev` 打開頁面，清到只剩一個標題
- 結果：瀏覽器顯示「ESG Idea Contest」，分頁標題也一樣；`npm run build` 通過，產出 `dist/`
- 實際裝到的版本：Vite 8、React 19、TypeScript 6

## 學到的概念

### 1. npm 與 package.json（跟 Go 對照）

| Go | Node / npm |
|---|---|
| `go.mod` | `package.json` |
| `go.sum` | `package-lock.json`（要 commit） |
| 全機共用的 module cache | 每個專案自己的 `node_modules/`（不 commit） |
| `go mod download` | `npm install` |
| Makefile target | `package.json` 的 `"scripts"`，用 `npm run <名稱>` 執行 |

`dependencies` 是瀏覽器執行時需要的套件，`devDependencies` 只在開發和 build 時用到。

### 2. Vite

- `npm run dev`：開發伺服器，收到 `.tsx` 的請求時當場轉成 JS，存檔後畫面自動更新（HMR）
- `npm run build`：先跑 `tsc -b` 做型別檢查，再打包成 `dist/` 裡的靜態檔案
- **dev 不做型別檢查**：dev 能跑，不代表 build 能過

### 3. JSX / TSX 與 component

```tsx
export default function App() {
  return <h1>ESG Idea Contest</h1>
}
```

- component 就是回傳 JSX 的函式，名字**一定要大寫開頭**
- JSX 用 `className` 而不是 `class`；`{}` 裡面放 JS 運算式；只能有一個根元素
- 匯出：TS 用 `export` 關鍵字，Go 用大寫開頭。`export default` 對應 `import App from ...`；
  具名匯出 `export { X }` 對應 `import { X } from ...`

### 4. 載入順序

```
index.html（空的 <div id="root"> + <script type="module" src="/src/main.tsx">）
  → main.tsx：createRoot(document.getElementById('root')!).render(<App />)
    → App.tsx：回傳 <h1>
```

- `main.tsx` 跟 `cmd/api/main.go` 一樣，只負責組裝
- `!` 是非空斷言：告訴 TS「這裡不會是 null」
- `<StrictMode>` 只在開發時作用，會刻意多執行一次某些程式碼，幫你抓出寫錯的地方

### 5. 用戶端渲染（CSR）

「檢視網頁原始碼」看到的 `<div id="root">` 是空的；DevTools Elements 裡才看得到 `<h1>`。
`<h1>` 是瀏覽器執行 JS 時塞進 DOM 的，不在伺服器送來的 HTML 裡。
Go 的 `html/template` 剛好相反，是伺服器端渲染（SSR）。

## 這一步遇到的問題

- **示範檔案跟說明對不上**：Vite 8 的範本沒有 `react.svg`，改成 `hero.png`、`vite.svg`、
  `public/icons.svg`。這三個都刪掉，只保留 `index.html` 用到的 `public/favicon.svg`
- **用 `.gitignore` 藏起沒用到的檔案**：不對。`.gitignore` 是給自動產生的檔案或只屬於本機的檔案用的。
  用不到的檔案應該直接刪掉。另外，沒有 `/` 的規則（例如 `vite.svg`）會比對任何層級，
  以後同名的檔案會被默默忽略
- **`.gitkeep`**：資料夾裡有了真正的檔案之後就不需要了，直接刪掉

## 自我檢查

**Q1. 把 `App` 改成小寫 `app`，並寫 `<app />`，會怎樣？**
React 會把它當成 HTML 標籤，DOM 裡出現一個空的 `<app></app>`，你寫的函式不會被呼叫。
console 會出現 `The tag <app> is unrecognized` 警告。`tsc` 會報錯，所以 `npm run build` 失敗；
但 `npm run dev` 不做型別檢查，所以只會看到一片空白。

**Q2. 「檢視網頁原始碼」看得到 `<h1>` 嗎？**
看不到。原始碼裡的 `#root` 是空的；`<h1>` 是 `main.tsx` 執行 `render(<App />)` 時，
在瀏覽器裡用 JS 加進 DOM 的（CSR）。
