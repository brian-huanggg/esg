# 4.9 platform-gitops：frontend 加 BACKEND_URL 與 Ingress

## 目標與結果

修改 platform-gitops 的 `apps/esg/frontend/` chart：注入 `BACKEND_URL`、啟用 Ingress（HTTPS）。
完成後 `helm template esg-frontend . -f values.yaml --set image.tag=testsha` 能 render 出：

- Deployment 帶 `BACKEND_URL=http://esg-backend:8080`，並掛 `/etc/nginx/conf.d` 的 `emptyDir`
- Ingress host 是 `esg.apps.pf.internal`，帶 `websecure` 和 `router.tls` 兩個 annotation

這一步只改 platform-gitops，ESG repo 沒有程式碼變更。

## 概念

### 請求怎麼流動

```text
瀏覽器 --HTTPS--> Traefik (websecure, TLS 終止) --> esg-frontend Service:80
                     nginx: /     -> 靜態檔
                            /api/ -> BACKEND_URL (http://esg-backend:8080)
```

瀏覽器只連同一個 host，所以前後端同源，不需要 CORS。

### BACKEND_URL 與 envsubst

`nginx.conf` 在 image 裡是範本（`/etc/nginx/templates/default.conf.template`）。
container 啟動時，entrypoint 用 envsubst 把 `${BACKEND_URL}` 換成環境變數的值，寫到 `/etc/nginx/conf.d/`。
Spring 類比：`application.yaml` 的 `${BACKEND_URL}` 屬性替換，只是這裡由 entrypoint 做。

### readOnlyRootFilesystem 與 emptyDir

根檔案系統唯讀時，entrypoint 無法寫 `conf.d`，腳本失敗，nginx 沒機會啟動，
Pod 進入 `CrashLoopBackOff`。解法是把 `conf.d` 掛成 `emptyDir`（可寫的暫存目錄）。

```yaml
volumeMounts:
  - { name: nginx-conf, mountPath: /etc/nginx/conf.d }
volumes:
  - name: nginx-conf
    emptyDir: {}
```

### Traefik annotation

```yaml
annotations:
  traefik.ingress.kubernetes.io/router.entrypoints: websecure
  traefik.ingress.kubernetes.io/router.tls: "true"
```

- Annotation 是 Kubernetes 物件上的 key/value 備註，只有 Traefik 會讀
- `router.entrypoints: websecure`：只開 443（`web` 是 80）
- `router.tls: "true"`：在這條路由啟用 TLS 終止。值必須是字串，要加引號
- 沒指定憑證，使用 Traefik 預設憑證，瀏覽器第一次要手動接受

### 為什麼一定要 HTTPS

Cookie 帶 `Secure`，瀏覽器只在 HTTPS 連線上儲存並送出。走 HTTP 時登入成功，
但下一個請求沒有 cookie，看起來像登入後馬上被登出。

## 學習者的問題

**Q：兩個 annotation 和 `Cookies are Secure` 那行註解是什麼意思？**
A：見上面「Traefik annotation」和「為什麼一定要 HTTPS」。註解的用途是記錄為什麼不能拿掉 TLS。

## 自我檢查

1. 漏掉 `/etc/nginx/conf.d` 的 `emptyDir`，Pod 會怎樣？
   答：容器啟動失敗並重啟（`CrashLoopBackOff`）。entrypoint 在啟動 nginx 前就要寫 `conf.d`，
   唯讀檔案系統寫不進去。不是 Pending（排程沒問題），也不是 502（nginx 根本沒起來）。
2. Ingress 只寫 `router.entrypoints: websecure`，漏掉 `router.tls: "true"` 會怎樣？
   答：443 上這條路由沒有啟用 TLS，HTTPS 連線無法正常完成。
