# 4.11 GitOps 迴圈：改一行到上線

## 目標與結果

改前端程式 → 推 image → 改 gitops 的 tag → ArgoCD 自動部署，走完一次完整迴圈：

- 瀏覽器看到首頁標題 `ESG Idea Contest v2`，登入頁和註冊頁有互相連結
- `esg-frontend` 的 image 是 `fc23bf3`，`esg-backend` 仍是 `8d85f2c`（沒改的服務不會動）
- `.status.sync.revision` 是 `878c031...`，等於 platform-gitops 的 HEAD

## 概念

### ArgoCD 只看 Git，不看 Harbor

```text
ESG repo:   改程式 -> commit (fc23bf3) -> make push -> Harbor 有 esg-*:fc23bf3
                                                          (叢集完全沒反應)
gitops:     改 values-dev.yaml 的 tag -> commit (878c031) -> push
ArgoCD:     發現 Git 變了 -> helm template -> 滾動更新 Pod
```

叢集的「期望狀態」只來自 Git。Harbor 有新 image 不代表要部署；Git 裡的 tag 改了才代表要部署。
Spring 類比：Jenkins 建完 jar 之後，還要有人改 deployment manifest 的版本號才會上線，這裡改 manifest 的是你的 commit。

### 兩個 repo、兩個 SHA

| 名稱 | 來源 repo | 用途 |
|---|---|---|
| `fc23bf3` | ESG app repo | image tag |
| `878c031...` | platform-gitops | `.status.sync.revision`，ArgoCD 這次 sync 的 commit |

```yaml
# apps/esg/frontend/values-dev.yaml
image:
  tag: "fc23bf3"   # 這一行 diff 就是「部署」
```

### 刷新與驗證

```bash
kubectl -n argocd annotate app esg-frontend argocd.argoproj.io/refresh=hard --overwrite
kubectl -n esg rollout status deploy/esg-frontend
kubectl -n argocd get app esg-frontend -o jsonpath='{.status.sync.revision}{"\n"}'
kubectl -n esg get deploy -o wide
```

### `<Link>` 與 router context

```tsx
import { Link } from 'react-router'
<Link to="/register">Register</Link>   // 只切換前端路由，不重新載入頁面
```

`Link` 要在 router context 裡才能 render。`Register.test.tsx` 原本沒包 router，所以改成包 `<MemoryRouter>`。

## 學習者的問題與解答

- **在哪裡放 Login / Register 連結？** 學習者原本想放 `App.tsx`，但 `/` 路由包在 `RequireAuth` 裡，看得到的人都已登入，所以改放在 `/login` 和 `/register` 兩頁互相連結。
- **輸入 `make` 失敗**：工作目錄在 `frontend/src`，不是 repo 根目錄，找不到 Makefile。指令前先 `cd` 到根目錄。
- **`kubectl get esg-frontend` 失敗**：漏了資源類型 `app`，正確是 `kubectl -n argocd get app esg-frontend`。

## 自我檢查

1. 只跑 `make push`、沒改 gitops 的 `values-dev.yaml`，叢集會怎樣？
   答：維持舊版。期望狀態來自 Git，Git 沒變就沒有需要調和的差異。
2. `.status.sync.revision` 為什麼不是 image tag `fc23bf3`？
   答：兩個 commit 來自不同 repo。revision 是 gitops repo 被 sync 的 commit，tag 取自 ESG app repo 的 commit。
