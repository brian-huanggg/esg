# 1.2 手寫一個 HTTP handler

> tag：`step-01-02`　檔案：`backend/cmd/api/main.go`　對應：後端 2.5（狀態碼）

## 目標與結果

`curl localhost:8080/api/health` 回傳 `{"status":"ok"}`，狀態碼 200，
`Content-Type: application/json`。

| 請求 | 結果 |
|---|---|
| `GET /api/health` | `200`，`{"status":"ok"}` |
| `POST /api/health` | `405 Method Not Allowed`，附 `Allow: GET, HEAD` |
| `GET /api/nope` | `404 Not Found` |

405 和 404 是 Go 預設的純文字回應，之後會統一成 JSON。

## 程式碼

```go
func main() {
	mux := http.NewServeMux()
	// Method in the pattern (Go 1.22+): other methods get 405 for free.
	mux.HandleFunc("GET /api/health", handleHealth)

	log.Println("listening on :8080")
	// ListenAndServe only returns on failure, e.g. the port is already in use.
	log.Fatal(http.ListenAndServe(":8080", mux))
}

func handleHealth(w http.ResponseWriter, r *http.Request) {
	// Headers must be set before WriteHeader; once sent they cannot change.
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(http.StatusOK)

	// The status line is already sent, so an encode error can only be logged.
	if err := json.NewEncoder(w).Encode(map[string]string{"status": "ok"}); err != nil {
		log.Printf("encode health response: %v", err)
	}
}
```

## 概念

用餐廳來比喻 HTTP 伺服器：

| 餐廳 | Go |
|---|---|
| 門口帶位的人 | 路由器（router）：`http.ServeMux` |
| 負責一種餐點的櫃台 | 處理函式（handler） |
| 客人的點單 | `*http.Request` |
| 出餐托盤：先貼標籤，再放食物 | `http.ResponseWriter`：先寫 header，再寫 body |
| 開門營業 | `http.ListenAndServe` |

- **`net/http`**：Go 的標準函式庫本身就有 HTTP 伺服器，不需要框架。
  TypeScript 那邊通常要裝 Express 之類的套件。
- **自己建 `ServeMux`**：不用全域的預設路由器，這樣 1.3 寫測試時可以把它拿進測試裡用。
- **函式當成值傳遞**：`HandleFunc(pattern, handleHealth)` 不加括號，是把函式交給路由器，
  等請求進來才呼叫。跟 TS 的 `app.get(path, handleHealth)` 一樣。
- **Go 不能有沒用到的 import**，否則編譯不會過。TS 只會給警告。
  這條規則只管 import 和變數，不管函式參數，所以 handler 沒用到 `r` 也沒關係。
- **`if x := ...; 條件`**：先執行分號前面那句，再判斷條件。`x` 只在這個 `if` 裡面有效。
- **Go 沒有例外（exception）**：錯誤是函式回傳的值，要自己檢查。TS 用的是 `try/catch`。

## 問題與解答

### `Header().Set` 和 `WriteHeader` 差在哪裡？

| | `w.Header().Set(k, v)` | `w.WriteHeader(code)` |
|---|---|---|
| 做什麼 | 在 header 清單上加一筆 | 把狀態碼和整份 header 一次送出去 |
| 會不會送出資料 | 不會，先記下來 | 會，送出後就改不了 |
| 比喻 | 貼標籤 | 封箱寄出 |

- `w.Header()` 回傳一個 map（`http.Header`），就像寄出前的草稿。
  `WriteHeader` 會把**當下**草稿上的內容送出去，之後再 `Set` 不會有效果。
- 沒有呼叫 `WriteHeader` 時，第一次寫 body 會自動呼叫 `WriteHeader(200)`。

### 為什麼路由沒寫 `GET`，`POST` 也會進來？

路由樣式的格式是 `[方法 ]路徑`，方法可以不寫。不寫的時候，所有方法都會進到同一個 handler。
Go 1.22 以前只能寫路徑，所以 handler 要自己檢查方法：

```go
// Pre-1.22 style: the handler has to reject other methods itself.
if r.Method != http.MethodGet {
	http.Error(w, "method not allowed", http.StatusMethodNotAllowed)
	return
}
```

把方法寫進路由樣式，Go 會自動回 405，也會補上 `Allow` header。
註冊 `GET` 時，`HEAD` 也會走同一個 handler，所以 `Allow` 是 `GET, HEAD`。

### `log.Fatal` 的作用是什麼？

`log.Fatal(x)` 等於 `log.Print(x)` 加上 `os.Exit(1)`：印出錯誤，然後用 exit code 1 結束程式。

| 寫法 | 8080 port 已經被佔用時 |
|---|---|
| `http.ListenAndServe(":8080", mux)` | 錯誤被丟掉，exit code 是 0，看起來像正常結束 |
| `log.Fatal(http.ListenAndServe(...))` | 印出 `bind: address already in use`，exit code 是 1 |

- shell、Docker、Kubernetes 都靠 exit code 判斷程式有沒有失敗，然後決定要不要重新啟動。
- **只能在 `main` 裡用。** 在 handler 裡用的話，一個請求出錯就會讓整個伺服器停掉。
- `os.Exit` 會直接結束程式，`defer` 的程式碼不會執行。

### 為什麼要 `NewEncoder` 加上 `Encode`，還要建立一個 map？

```go
json.NewEncoder(w).Encode(map[string]string{"status": "ok"})
//   ① 建立跟 w 綁在一起的編碼器
//                  ② 轉成 JSON，直接寫進 w
//                          ③ 要轉換的資料，像 TS 的 Record<string, string>
```

另一種寫法是 `json.Marshal`：

| | `NewEncoder(w).Encode(v)` | `json.Marshal(v)` + `w.Write(b)` |
|---|---|---|
| 結果 | 直接寫進 `w` | 先得到 `[]byte`，再自己寫出去 |
| 編碼失敗時 | 狀態碼已經送出，只能 log | 還沒送出，可以改回 500 |
| 結尾 | 自動加一個換行（所以 Content-Length 是 16） | 不加 |

正式的寫法通常用 struct，欄位和型別固定，打錯欄位名稱時編譯就不會過：

```go
type healthResponse struct {
	Status string `json:"status"`
}
```

這個 handler 下一步就會換掉，1.4 之後 struct 會由 OpenAPI 規格自動產生，所以現在先用 map。

## 自我檢查

**Q1.** 把 `WriteHeader(http.StatusOK)` 移到 `Header().Set("Content-Type", ...)` 前面，
`Content-Type` 還會是 `application/json` 嗎？

不會。`WriteHeader` 送出時還沒設定 `Content-Type`，Go 會看 body 的開頭自己猜，
結果是 `text/plain; charset=utf-8`。之後才執行的 `Set` 沒有效果。

**Q2.** 把路由樣式改成 `"/api/health"`（不寫方法），`POST` 會拿到什麼？

`200` 和 `{"status":"ok"}`。不寫方法時，所有方法都會進到這個 handler。

## 小技巧

- `go run` 啟動的伺服器會一直執行，要在另一個終端機跑，用 `Ctrl+C` 停掉。
- 在 Claude Code 裡用 `!` 跑 curl 時，輸出不是接到終端機，curl 會印出進度條。
  加 `-s` 可以關掉。
