# Step 2.9 前端 router 與註冊表單

## 目標與結果

瀏覽器開 `/register`，有工號、姓名、密碼三個欄位。送出後呼叫 `POST /api/accounts`，
成功顯示成功畫面，Network 面板看到 201。對應 PRD 2.1 帳號。

這一步新增 `react-router`、`openapi-fetch`，另外依學習者要求加入 Prettier 和
`eslint-config-prettier`，並新增 `make lint-frontend`、`make format-frontend`。

## 學到的概念

### react-router：前端路由

類似 Spring 的 `@RequestMapping`，但路由表要手動寫。`BrowserRouter` 放在 `main.tsx`，
用 context 把網址傳給底下的元件；`Routes` 選出符合網址的 `Route`。

```tsx
<Routes>
  <Route path="/register" element={<Register />} />
</Routes>
```

測試時不能用 `BrowserRouter`（jsdom 沒有真實 history），改用 `MemoryRouter`：

```tsx
<MemoryRouter initialEntries={['/']}>
  <App />
</MemoryRouter>
```

### 受控表單（controlled input）

輸入框的值永遠等於 state。`value` 和 `onChange` 必須一起寫，只寫 `value` 會讓輸入框打不進字。

```tsx
const [name, setName] = useState('')
<input value={name} onChange={(e) => setName(e.target.value)} />
```

### openapi-fetch：型別化的 fetch

用 `schema.d.ts` 的 `paths` 型別，路徑和 body 寫錯會在編譯時報錯。

```ts
export const api = createClient<paths>()
const { data, error } = await api.POST('/api/accounts', { body })
```

HTTP 錯誤（409、422）**不會丟 exception**，而是回傳在 `error` 裡，要自己檢查。
這和 Go 的 `if err != nil` 一樣，與 Java 的 exception 往上拋不同。
網路斷線這類 `fetch` 本身的失敗仍會 throw，留到 2.10 處理。

### 提交中狀態

用 `'idle' | 'submitting' | 'done'` 的聯集型別（union type）。提交中把按鈕 `disabled`，避免連點送出兩次。
`e.preventDefault()` 擋掉表單預設的整頁重新載入，否則 state 會消失。

### Prettier 與 ESLint 分工

Prettier 只管排版，ESLint 管程式品質。`eslint-config-prettier` 要放在 `extends` 最後，
關掉 ESLint 裡和 Prettier 衝突的排版規則。`schema.d.ts` 是產生的檔案，放進 `.prettierignore`。

## 問題與解答

- **`App.test.tsx` 為什麼壞了？** `App` 用了 `<Routes>`，沒有 Router 包住時讀不到網址，
  錯誤是 `useRoutes() may be used only in the context of a <Router> component`。
  Router 放在 `App` 外面，所以測試可以用 `MemoryRouter`，正式環境用 `BrowserRouter`。
- **lint 和 build 的 `'Link' is defined but never used`？** import 了但沒用到，
  `@typescript-eslint/no-unused-vars` 和 `tsc` 的 `noUnusedLocals` 都會報。

## 自我檢查

1. 只寫 `value={name}`、不寫 `onChange`，打字時會怎樣？
   答：輸入框看起來打不進字。每次重畫都用沒變的 state 覆蓋輸入框。
2. 伺服器回 409 時，`api.POST` 怎麼處理？
   答：回傳的 `error` 有值，程式碼走到 `if (error)`。HTTP 錯誤是一般回傳值，不是 exception。
   （第一次選「丟 exception」、第二次選「error 是 undefined」，第三次答對。）
